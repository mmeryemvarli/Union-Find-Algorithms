# Union-Find & Disjoint-Set Data Structures

A Python project implementing various versions of the **Union-Find (Disjoint-Set)** data structure to demonstrate trade-offs between Quick Find, Quick Union, and Weighted Quick Union algorithms.

## Implementations & Real-World Applications

1. **Quick Find (`SocialNetworkQF`):** Fast connectivity check and social network friendship simulation[cite: 9].
2. **Quick Union (`NetworkQU`):** Tree-based root tracking for network cable connections[cite: 9].
3. **Weighted Quick Union (`WeightedQU`):** Tree balancing optimization using component sizes[cite: 9].
4. **Percolation Simulation (`UnionFind`):** Grid percolation model using virtual top and bottom nodes[cite: 9].
